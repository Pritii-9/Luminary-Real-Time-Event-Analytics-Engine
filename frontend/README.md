# Luminary Frontend

This is the frontend for the Luminary real-time analytics platform. It is built using React, TypeScript, and Vite.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Tech Stack
- React 18
- React Router v6
- Tailwind CSS v3
- Vite
- Lucide React (Icons)
- Recharts
